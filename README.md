# Forge 🔥
### SHOW UP. STRIKE. EARN.

Human intelligence task marketplace built natively for Solana Seeker.

## What it does
- Connect Seed Vault via Mobile Wallet Adapter 2.0
- Complete AI training tasks (image classification, sentiment analysis, data verification)
- Every answer submitted as a signed on-chain Memo transaction
- Instant payout confirmation with Solana Explorer link

## Tech Stack
- React Native + Expo
- @wallet-ui/react-native-web3js (MWA 2.0)
- @solana/spl-memo (on-chain task verification)
- Solana Devnet

## Status
Working Android build. Tested on Android emulator with MWA wallet integration.
